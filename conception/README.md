# Dossier de Conception MandaCare

Ce dossier contient les documents de conception du MVP mobile/tablette.

## Fichiers

- `backlog_mvp.md` : user stories, priorités et critères d'acceptation.
- `matrice_roles_permissions.md` : droits par rôle et restrictions sensibles.
- `modele_donnees.md` : entités principales, champs et relations.
- `parcours_mobile_tablette.md` : parcours écran par écran pour mobile et tablette.
- `templates_pdf.md` : structure des PDF officiels du MVP.

## Source de référence

La source fonctionnelle propre est :

`expressions_besoins/expression_besoins_mobile_tablette.md`

Le fichier `expressions_besoins/expression_besoins_old.md` est une archive de travail et ne doit pas être utilisé comme source principale.

## Périmètre

La V1 reste limitée à mobile/tablette. Le desktop, le portail patient, le multi-centres, l'offline complet et les intégrations automatiques WhatsApp Business / Mobile Money sont hors périmètre MVP.
